The Region Editor lists every region drawn on the currently displayed image. Open it with the button in the diagram toolbar: it opens as a floating dialog you can drag, resize, and leave open while you draw on the image. Regions are tracked per image: switching to another image hides these and shows that image's regions; switching back restores them. Edits in the table apply live to the diagram — there is no save or cancel.

Creating regions

Use the diagram toolbar tools to draw new regions: rectangle, polyline, freeform path, brush, or wand. Anything you draw appears immediately in the table, with the class name "Region" by default.

The table columns

  • Class — the region's class. Pick a class from the dropdown (its colour follows), or use the for a free-form name.
  • Surface — the region's area, in µm²/mm² when the image carries a physical pixel size, otherwise in px². Holes (donuts) and multi-part regions are accounted for.
  • The trash icon at the end of a row deletes that one region.
  • Use "x512" to round all rectangle widths/heights to the nearest multiple of 512.

Region geometry is edited on the diagram itself (drag vertices, the vertex tools, brush/wand, and the right-click region actions), not in this table.

Selecting rows

  • Click a row to select it. The corresponding region is highlighted in the diagram (Plotly shows its edit handles; the OpenSeadragon image view highlights it and shows its handles in select mode).
  • Ctrl/Cmd+click to add or remove a row from the selection. Shift+click to extend the selection in a range.
  • Selecting a region in the diagram highlights the matching row in the table.
  • Clicks on the colour picker, the trash icon, or the active class-edit input do not change the selection — that's standard PrimeNG behaviour.

Bulk actions on the selected rows

  • Select every region in the table at once (also a right-click action on the image).
  • Edit the label on every selected row at once.
  • Delete every selected region — both from the table and the diagram.
  • Delete every region on this image.

Annotation classes & colours (presets)

Preset a class once — a name and a colour — and every region with that class name is drawn in that colour, including regions loaded from a GeoJSON later. The preset colour is the source of truth: on load it overrides the colour stored in the file, so a given annotation type always looks the same across images and sessions.

Set up your classes in the annotation-class manager — Manage:

  1. Add class, then type the class name exactly as it appears in your data (e.g. Tumor) and pick its colour from the swatch. Repeat for each class.
  2. Optionally: edit the fallback palette (colours given to classes that aren't in your list), toggle auto-add (adds unmatched classes found on load), and choose exact vs. normalized name matching — normalized ignores case and surrounding spaces, so tumor matches Tumor.
  3. Apply. Presets are saved per user on the server, so they follow you across images and sessions. You can also reset to defaults or import / export the set as JSON to share it.

Next time you open or import a GeoJSON whose regions carry those class names, each region is shown in its preset colour automatically — no re-colouring needed. A class that isn't in your list instead gets a stable colour from the fallback palette.

Day to day:

  • The class strip above the table lists your presets with their colours. Click a class to make it active (new regions inherit it); with rows selected, clicking a class re-classifies them.
  • The Class column dropdown re-classifies one region to a preset (its colour follows), or use the for a free-form name.
  • Recolour a class from its swatch (class strip or Manage) and every region of that class updates at once.
  • Deleting a class reassigns its regions to the default Region class.
  • A colour you set on a single region ( Selected regions) is kept and is not overridden by its class.

Region actions (right-click the diagram)

Right-click a region — or the current multi-selection — on the diagram for the "Selected region(s)" actions:

  • Merge / group — combine 2+ selected regions into one (it may end up multi-part if the pieces don't touch).
  • Ungroup — split a multi-part region back into separate regions.
  • Inverse — replace the selection with everything outside it (the regions become holes in the image rectangle).
  • Simplify — reduce the vertex count (Douglas–Peucker) by a pixel threshold; pick a preset or a custom value.
  • Convert to Bézier / to polygon and Delete.

Display options

  • Toggle showing class labels on every region in the diagram (slower with many regions).

Import / export

  • Import regions from a GeoJSON file.
  • Export the current image's regions to a GeoJSON file. (The per-image cache is in-memory only — exporting is how you persist regions across sessions.)
