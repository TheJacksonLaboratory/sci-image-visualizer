# QA: Regions

Test cases for drawing, selecting and editing regions on the image, undo/redo, the right-click region actions
and the related keyboard shortcuts. See [How to use the plan](index.md). Reference:
[Region tools](../reference/region-tools.md), [Region actions](../reference/region-actions.md),
[Keyboard shortcuts](../reference/keyboard-shortcuts.md).

Unless a case says otherwise, use `img01.png` in the **Image** view with no regions, and press ++s++ before each
case to start from no armed tool.
