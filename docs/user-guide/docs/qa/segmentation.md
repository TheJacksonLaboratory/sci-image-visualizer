# QA: AI segmentation

Test cases for the in-browser segmentation tools: SAM box prompts, SAM point prompts, the model picker,
Cellpose, progress toasts and model caching. See [How to use the plan](index.md). Reference:
[AI segmentation](../reference/segmentation.md).

!!! note "Downloads"
    The first run of each model downloads it: micro-sam ViT-T about 14 MB, ViT-B about 172 MB, patho-sam about
    180 MB (int8 about 100 MB), Cellpose-SAM about 588 MB. Use a fast connection, and clear the site's data (or
    use a private window) for the cases that test the first download.

Unless a case says otherwise, use `img04.png` (fluorescent cells) in the **Image** view.
