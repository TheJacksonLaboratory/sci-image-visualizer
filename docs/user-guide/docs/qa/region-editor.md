# QA: Region Editor and classes

Test cases for the Region Editor (table, toolbar, dialogs), annotation classes and presets, GeoJSON, label
volume and mask import/export, large region sources and 3D class features. See
[How to use the plan](index.md). Reference: [Region Editor](../reference/region-editor.md),
[Annotation classes](../reference/annotation-classes.md), [GeoJSON import and export](../reference/geojson.md).

Unless a case says otherwise, use `img01.png` (no pixel size) or WSI `CMU-1` (with a pixel size) in the
**Image** view, with the Region Editor open.
