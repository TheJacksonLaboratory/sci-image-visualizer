# QA: Viewing

Test cases for opening images, the toolbar, plot types, navigation, display settings, stacks, 3D views, the
slice editor, intensity profiles and image export. See [How to use the plan](index.md) for IDs, priorities
and recording results. Reference: [Toolbar](../reference/toolbar.md), [Plot types](../reference/plot-types.md),
[Navigation](../reference/navigation.md), [Channels & Histogram](../reference/channels-histogram.md),
[Stacks, volumes and 3D](../reference/stacks-3d.md), [Intensity profile lines](../reference/intensity-profiles.md).

Unless a case says otherwise, start from the [live demo](https://thejacksonlaboratory.github.io/sci-image-visualizer/)
freshly loaded, in the primary browser, with WebGPU available.
