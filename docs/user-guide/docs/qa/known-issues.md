# Known issues to confirm

This page lists behaviours found while documenting SIV 0.19.0 that look like defects, or where earlier
documentation (the in-app help dialogs that this guide replaces, the design notes, the example README) said
something the code does not do. Each item is a hypothesis from reading the code: **confirm it** with the linked
test case, then either open an issue or, if the behaviour is intended, move it into the reference pages and
retire it here.

Source references are to files under `src/lib/` in the
[repository](https://github.com/TheJacksonLaboratory/sci-image-visualizer) at 0.19.0 unless shown otherwise.

| Status        | Meaning                                                                    |
| ------------- | -------------------------------------------------------------------------- |
| **Suspected** | Found by reading the code; not yet reproduced.                             |
| **Confirmed** | Reproduced; an issue is linked.                                            |
| **Intended**  | Confirmed as the desired behaviour; documented in the reference, retired.  |
| **Doc drift** | The code is fine; an older document said otherwise. Fixed by this guide.   |
